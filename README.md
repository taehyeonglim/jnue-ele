# 전주교대 초등교육과 — 교육을 두루, 따뜻하게

LAMP 전공탐색용 한 페이지 랜딩(발표 화면 겸용). https://taehyeonglim.github.io/jnue-elementary/

- 정적 HTML/CSS/JS, 빌드 없음. 수정 후 `git push` 하면 1~2분 뒤 반영(발표 PC는 강력 새로고침).
- 발표 모드: 가로 1024px 이상에서 자동, `P` 키로 전환, `F` 전체화면. →/Space/PageDown 다음 화면, ←/PageUp 이전, 숫자키 1~9 = 화면 배지 번호, 0 = 시작, Home = 오프닝, End = 끝.
- 0번 화면 오프닝 영상(`media/opening.mp4`): 클리커 첫 누름 = 재생, 한 번 더 = 다음 화면, 끝나면 자동으로 시작 화면.
- 영상: `media/` 에 mp4 직접 호스팅(opening·trailer·v23·v24, 각 100MB 미만). 원본·제작 도구는 드라이브 건 폴더와 `program-chair/tools/opening`·`tools/trailer`.
- 이전 판(2026-10, 38대 학생회 테마)은 git 태그 `lamp-v1-pink`.
